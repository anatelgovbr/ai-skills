# Avisos de terceiros

O projeto é distribuído sob a GNU General Public License v3.0 (GPL-3.0), conforme [`LICENSE`](./LICENSE). Este arquivo é a fonte de proveniência, revisão, licença e condição de distribuição do material de terceiros mantido no checkout. A tabela do README serve somente para descoberta e acionamento.

As skills vendorizadas mantêm suas próprias licenças. Os textos Apache-2.0 acompanham `frontend-design` e `skill-creator`; os avisos MIT de `caveman` e `writing-for-agents` estão reproduzidos abaixo. Nenhuma skill vendorizada tinha um `NOTICE` próprio no snapshot registrado. Se uma origem passar a fornecer esse arquivo, preserve seu conteúdo legível em um `NOTICE` na raiz ou neste documento, conforme a licença aplicável.

Esta separação é uma decisão de organização adequada ao projeto, não uma dispensa de obrigações das licenças. O README mantém somente a descoberta e o acionamento das skills, enquanto este arquivo concentra origem, revisão, licença e condição de distribuição. Assim, a tabela principal continua legível sem perder a proveniência necessária para auditoria. Avisos legais fornecidos pela origem continuam tendo precedência e devem ser preservados integralmente quando aplicáveis.
